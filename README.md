# Lecture Notes
*Read this in other languages: [Español](#notas-de-clase)*

This repository contains my lecture notes and course materials. The compiled PDF files are readily available for anyone to view or download.

## Repository Structure
Currently, the repository contains the following:
* **`logic(ES)/`**: Materials for Logic. 

## LaTeX Libraries
The source files (`.tex`) are built using the `beamer` document class with the `metropolis` theme and `owl` color scheme. The following main packages are required:
* `babel` and `inputenc`
* `amsfonts`, `amsmath`, `amssymb`, `amsthm`
* `graphicx`
* `tikz`
